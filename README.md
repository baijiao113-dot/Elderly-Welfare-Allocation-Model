# 基于多目标优化的老年福利慰问金分配与调整模型

**陕西师范大学研究生数学建模竞赛校内赛 项目**  
| **成员**：闫心雨、李喜平、白姣姣 | **指导老师**：张建国

---

## 📋 项目简介

本项目针对A市老年福利慰问金分配问题，构建了一套**数据驱动的多目标优化分配体系**。在严格的预算约束、百元整数约束、信赖保护原则等现实条件下，实现对困难老人兜底帮扶与高层次人才激励的平衡。

**核心目标**：通过数据分析与建模方法，提升福利资金分配的**公平性、精准性与政策导向性**。

---

## ✨ 项目亮点

- **全流程数据分析实践**：完成数据清洗、特征工程、探索性分析到模型评估的完整链路
- **多模型融合建模**：结合统计模型 + 多准则决策 + 整数优化方法
- **政策与业务结合**：将多维贫困指数（MPI）、信赖保护原则等真实政策约束转化为可计算的数学模型
- **模型鲁棒性验证**：通过参数敏感性分析、基尼系数、泰尔指数等指标评估公平性与稳定性

---

## 🛠️ 技术栈

- **编程语言**：Python
- **数据处理**：Pandas, NumPy
- **数据可视化**：Matplotlib, Seaborn
- **统计建模**：Statsmodels（多元线性回归）、Scikit-learn（决策树）
- **多准则决策**：AHP层次分析法 + 熵权法
- **条件约束**：改进最大余额法

## 🚀 主要工作与实现

### 1. 数据预处理
- 缺失值填充、异常值处理、分类变量编码
- Z-score 标准化 + 正负向指标处理

### 2. 方案评价（问题一）
- 多元线性回归 + 决策树回归
- 通过 R²、显著性检验、决策路径可视化对比三种方案

### 3. 最优分配模型（问题二）
- **MPI 多维贫困指数** 实现特困群体刚性兜底
- **AHP + 熵权法** 融合主客观权重计算综合福利得分
- **改进最大余额法** 解决百元整数约束与预算零误差问题

### 4. 追加预算调整（问题三）
- 信赖保护原则量化（20%人数限制 + 比例变化约束）
- 锁定保护 + 边界拦截 + 残差补偿机制

### 5. 政策条款与对比分析（问题四）

---

## 📊 核心成果

- 成功实现预算**零误差闭环分配**（总金额精确用尽）
- 模型在20万→30万预算场景下均保持良好稳健性
- 通过基尼系数与泰尔指数验证分配公平性显著提升
- 形成可落地的规范化分配政策条款
